# Easy Weather

Interactive map that plays the next 48 hours of California weather: rain/snow chance, temperature and wind for 27 forecast cities, with search for about 1,100 towns and all 58 counties.

Open it: https://mformanas.github.io/Easy-weather/

- Loads the live hourly forecast from [Open-Meteo](https://open-meteo.com/) each time it opens, and every 30 minutes while open.
- Keeps the last forecast on your device, so it still works offline.
- Falls back to a forecast saved in the page if neither is available.

Places between the 27 forecast cities are estimated by blending the nearest cities by distance.

Weather data by Open-Meteo.com (CC BY 4.0).
